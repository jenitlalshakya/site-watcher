# My Update Checker (GitHub repo: site-watcher)

**My Update Checker** (repo: site-watcher) is a browser extension that monitors websites in the background and notifies you whenever there’s a new update.

## Features

- Monitor any website for updates.
- Background monitoring – works even when the site is not open.
- Desktop notifications when content changes.
- Easy to configure and use.
- Lightweight and fast.

## Installation

1. **Download the extension** folder from this repository.
2. Open your browser and go to the **Extensions** page:
   - Chrome: `chrome://extensions/`
   - Edge: `edge://extensions/`
   - Firefox: `about:addons`
3. Enable **Developer Mode** (Chrome/Edge) or **Debug Mode** (Firefox).
4. Click **Load unpacked** and select the extension folder.
5. The extension will appear in your browser toolbar.

## Usage

1. Open the extension popup.
2. Add the URL of the site you want to watch.
3. Configure the checking interval.
4. Turn on notifications.
5. Sit back and relax — Site Watcher will alert you when changes occur.

## Permissions

- `storage` – to save your monitored sites and settings.
- `notifications` – to send alerts when a website updates.
